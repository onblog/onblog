# 设计笔记

`wordtk.com` 是一张会自己说话的名片：陌生人十秒内要知道 Martin 在做什么，回头客要能最快走到工具本身。

## 题材决定风格

这套作品本身就有很强的签名感：小、本地优先、名字里带一只猫（喵喵吧台、喵喵笔记、猫窝博客）。所以卡通不是
套在通用版式上的装饰，而是题材的母语。页面上每一样东西都从这里长出来：童话书一样的纸面、粗墨线描边、
硬边偏移投影、微微歪着的贴纸、围着头像手绘的猫耳。

## 颜色

| Token | 色值 | 用在哪 |
| --- | --- | --- |
| `--paper` | `#FFF6E4` | 页面底色 + 22px 点阵 |
| `--panel` | `#FFFCF2` | 内容面板 |
| `--card` | `#FFFFFF` | 项目卡片、按钮、标签 |
| `--ink` | `#2B2622` | 正文、所有 3px 描边、硬投影 |
| `--ink-2` | `#74695D` | 次要文字（在 `--card` 上对比度 5.1:1） |
| `--gold` | `#C99538` | 唯一强调色：手绘下划线、标签、星标胶囊 |
| `--gold-soft` | `#F6D68E` | 贴纸填充（取自赞赏码） |
| `--sky` / `--mint` / `--blush` | `#D8EFFA` / `#DCF1E4` / `#FBE2E0` | 三个辅助分类色 |

金色是从随站点一起发布的微信赞赏码里取的，所以那张赞赏卡片看起来不像从别处搬来的。金色永远不用在正文上 ——
这个尺寸下它的对比度不够。

## 字体

- 标题与正文都用系统圆体栈：`ui-rounded` / SF Pro Rounded / 圆体-简，正文回落 PingFang SC。**不用 Web 字体。**
  一个托管字体是最容易给大陆访客加上 300KB 和一次阻塞渲染请求的做法，而这个页面要求的是"立刻就开"。
- 名字是唯一用海报尺寸（clamp 到 118px）的元素，配一条手绘下划线；其余按 26 / 19 / 16 / 14.5 / 13.5 逐级递减。
- 正文每行控制在 46 字以内。

栏目标题做成压在面板边框上的文件夹标签，而不是常见的大写小字眉标：标签编码的是"你在哪一块"，属于结构信息，
不是装饰。内容左对齐，栏宽封在 1080px。

## 动效

只做一次编排好的入场：首屏元素带短错峰落下，随后卡片与时间线节点在第一次滚动时用 `IntersectionObserver`
淡入一次。hover 只回应指针（卡片抬 2px、赞赏码转正）。`prefers-reduced-motion: reduce` 会关掉全部动效。

## 刻意不做的事

- **不做深色模式。** 奶油纸面 + 墨线描边就是这套身份；深色版要再配一套描边和投影才能保住卡通感，维护面积翻倍。
- **页面没有框架、没有构建步骤。** `public/` 原样发布。
- **页面上没有第三方徽章、字体、统计和嵌入。** 只有 README 用 shields.io 徽章，代价是 README 的一次图片请求，
  而不是访客的渲染路径。
- **不编数字。** 星标、fork、关注者全部来自构建时的 GitHub 接口。

## 双语文案

`public/index.html` 里每个需要翻译的节点都带 `data-en` 与 `data-zh`；`public/app.js` 交换 `textContent`
并把选择存进 `localStorage`（`onblog:lang`），默认跟随浏览器语言。项目数据带 `descEn` / `descZh`，
由仓库描述在第一个汉字处切开。只存在于 JS 里的界面文案（筛选标签、"在线体验"）也保持双语。
