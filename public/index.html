关于我

我是 Martin。白天写 Java 和 JavaScript，晚上做一点自己真的会用的小工具 —— 喵喵剪贴板、喵喵笔记、字压都是这么来的。

判断标准只有一条：装上之后不需要教程。所以它们大多本地优先，不要账号，中间也没有一层云端黑盒。

这几年我在把它们一个个搬到 Cloudflare Workers 上 —— 一个小工具不花服务器钱，也能一年 365 天在线。
